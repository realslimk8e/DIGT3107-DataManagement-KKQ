# DIGT 3107 – Phase 2

This repository contains the Phase 2 database implementation for the Elmwood University Room/Hotel Booking System.

## Files

- `create_tables.sql` – creates the database tables, primary keys, foreign keys, and constraints
- `insert_data.sql` – inserts sample data into each table
- `team#_phase2.pdf` – contains table descriptions and MySQL Workbench screenshots

## Database Tables

- Guest
- RoomType
- Room
- Booking

The database was created and tested using MySQL Workbench.
