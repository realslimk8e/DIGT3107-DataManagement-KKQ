# DIGT 3107 – Database Project

This repository contains the database implementation for the Elmwood University Room/Hotel Booking System.

## Phase 2 – Database Implementation

Phase 2 converts the ER diagram into a working MySQL relational database.

### Files
- `create_tables.sql` – creates the database tables, primary keys, foreign keys, and constraints
- `insert_data.sql` – inserts sample data for testing
- `team#_phase2.pdf` – contains table descriptions and MySQL Workbench screenshots

### Database Tables
- Guest
- RoomType
- Room
- Booking

## Phase 3 – Complex SQL Queries

Phase 3 implements and tests more complex SQL queries that support booking operations and reporting.

### Files
- `complex_queries.sql` – contains 8 complex SQL queries
- `team#_phase3.pdf` – contains query descriptions, expected uses, and MySQL Workbench result screenshots

### Queries
1. Available rooms for a selected date range
2. Booking history for a specific guest
3. Most-booked room types
4. Total 2025 bookings and revenue with a 10% discount
5. Monthly revenue by room type
6. Cancellation trends by month
7. Cancellation trends by room type
8. Cancellation trends by month and room type

The database and queries were created and tested using MySQL Workbench.
